# 🎬 YouTube Altyazı Stüdyosu

YouTube videolarının altyazılarını çeken, farklı dillere çeviren ve `.txt` ya da `.srt` formatlarında kaydetmenizi sağlayan modern bir masaüstü uygulaması.

## Özellikler
- Otomatik ve manuel YouTube altyazılarını çekme
- Çoklu dil çevirisi (Google Translate API entegrasyonu)
- Canlı önizleme
- `.txt` (Düz metin) ve `.srt` (Zaman damgalı altyazı) formatlarında kaydetme
- Modern karanlık mod (Dark mode) arayüzü
